### 🟢 Question 2 — Simple Calculator

Take two numbers from the user.

Print their:

* Sum
* Difference
* Product

Example:

Enter first number: 10
Enter second number: 5

Sum = 15
Difference = 5
Product = 50

**Concept:** Variables + Arithmetic Operators + Scanner

---

### 🟡 Question 3 — Calculate BMI

Ask the user for:

* Height in centimeters
* Weight in kilograms

Calculate BMI using:

BMI = weight / (height in meters × height in meters)

Example:

Enter height: 170
Enter weight: 65

BMI = 22.49

**Concept:** Variables + Data Types + Arithmetic

### 🟠 Question 6 — Student Grade

Ask the user for their marks.

Print the grade using these rules:

90 or above → A
75–89 → B
40–74 → C
Below 40 → Fail

Example:

Enter marks: 82

Grade = B

**Concept:** if-else

### 🔵 Question 9 — Multiplication Table

Ask the user for a number and print its multiplication table from **1 to 10**.

5 × 1 = 5
5 × 2 = 10

...

### 🔴 Question 10 — Keep Adding! 🧮

Ask the user to enter numbers one by one.

Keep adding them to a running total.

Stop when the user enters **0**.

Example:

Enter number: 10
Enter number: 20
Enter number: 5
Enter number: 15
Enter number: 0

Total = 50

**Important:** The 0 should stop the loop and should **not** be added to the total.

**Concept:** while loop + Scanner + Variables
