# ☕ Challenge 1 — Java Practice Questions

## Variables → Scanner → if-else → switch-case → Loops

Try to solve these questions yourself before checking the answers. 💻

### 1. Name & Age
Take the user's name and age using Scanner and print:

`Hi [name], you are [age] years old.`

### 2. Simple Calculator
Take two numbers as input and print their:
- Sum
- Difference
- Product

### 3. BMI Calculator
Take the user's height in centimeters and weight in kilograms, then calculate and print their BMI.

### 4. Even or Odd
Take a number as input and check whether it is even or odd using if-else.

### 5. Find the Largest
Take three numbers as input and find the largest number using if-else.

### 6. Student Grade
Take the user's marks and print the grade:

- 90+ → A
- 75–89 → B
- 40–74 → C
- Below 40 → Fail

### 7. Day Finder
Ask the user to enter a number from 1–7 and print the corresponding day using switch-case.

### 8. Print Numbers
Print numbers from 1 to 10 using a for loop.

### 9. Multiplication Table
Take a number from the user and print its multiplication table from 1 to 10 using a for loop.

### 10. Running Total
Ask the user to enter numbers one by one and keep adding them to a running total.

Stop taking input when the user enters `0`.

Use a while loop.
